# CineWatch TV API Service Boundary

This directory is the governed boundary for the CineWatch TV backend service.

`CWTV.V1.2.2` establishes metadata and tooling policy only. The FastAPI service skeleton begins in `CWTV.V1.2.3`.

The backend will own CineWatch application APIs, domain rules, rights enforcement, persistence access, provider-policy enforcement, and OpenAPI authority. No CineWatch feature implementation is introduced here yet.
